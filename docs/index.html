Kimai Plugin · GPL-3.0

Working Hours & Holidays

Open-source alternative to Kimai's commercial WorkContractBundle. Working hours, overtime, vacations, sickness, public holidays, and calendar integration — all in one plugin.

GitHub Download v1.0.0
Experimental — This plugin was entirely vibe-coded. Not all functionality is fully tested, especially permissions around the absence approval workflow. Test carefully before production use.

Features

Everything you need for absence management and overtime tracking, built into Kimai's existing UI.

📅

Working Times Integration

Absences and public holidays appear directly in Kimai's built-in Arbeitszeiten table — including known future days. Distinctive icons per absence type.

🌴

Vacation & Absence Management

Vacation (half-day), sickness (+ relatives), Freizeitausgleich, and custom absence types. Approval workflow with email notifications and edit-with-reapproval.

🌎

Public Holidays via ICS

Import holidays from curated regional calendars (Germany, Austria, Switzerland, 30+ countries) or any custom ICS URL. Auto-sync with a cron command.

📆

Per-User ICS Calendar

Each user gets a personal calendar subscription URL with their public holidays and approved absences — locale-aware, for Outlook, Google, or Apple Calendar.

📊

Absence Calendar & Reports

Full-year absence calendar with team view, CSV export, and per-absence workday count. Weekends and non-working days are automatically excluded.

🔒

Month Locks & Settings

Lock months for approval. Configurable calculation modes (compensate vs reduce), comment requirements, and workday timesheet restrictions. REST API included.

Compatibility

Designed as a drop-in alternative to the commercial Controlling plugin.

Requires

Kimai ≥ 2.64

PHP ≥ 8.1

Replaces

WorkContractBundle

Do not install both at the same time. Remove the commercial plugin first.

Installation

Clone, reload, done.

Classic Install

cd var/plugins
git clone https://github.com/shrippen/kimai-holiday-bundle.git HolidayBundle

bin/console kimai:reload -n
bin/console kimai:bundle:holiday:install

Docker

docker exec -it CONTAINER \
  /opt/kimai/bin/console kimai:reload -n

docker exec -it CONTAINER \
  /opt/kimai/bin/console kimai:bundle:holiday:install

Then assign permissions under System → Roles (section Working Hours & Holidays).

REST API

Programmatic access to absences and public holidays.

GET  /api/holiday/absences?year=2026
POST /api/holiday/absences
POST /api/holiday/absences/{id}/approve
POST /api/holiday/absences/{id}/reject
GET  /api/holiday/absences/types
GET  /api/holiday/public-holidays?year=2026
GET  /api/holiday/public-holidays/calendar
